# 用户网页开发需求文档

## 1. 产品目标

建立完整的 AI 小说创作工作台，让用户能够从创意开始，持续管理设定、规划、章节生成、编辑和导出。

## 2. 第一阶段需求

### 2.1 账户与工作台

- 注册、登录、退出和找回凭证。
- 查看作品列表、最近编辑和生成状态。
- 创建、归档和删除作品。
- 工作台采用固定窗口布局：左侧作品栏固定，右侧聊天/任务视图内部滚动。
- 左侧栏支持折叠/展开，折叠状态需要持久化。
- 默认优先展示聊天记录和任务状态；没有对话记录时展示 32px 空白态欢迎文案。
- 支持默认粉色主题、多主题切换和自定义主题色，主题设置需要持久化。
- 对话框支持切换后端开放的大模型，默认模型需要持久化。
- 聊天会话和消息需要保存到后端数据库，刷新页面后可恢复。

### 2.2 小说初始化

- 输入创意、题材和基础文风要求。
- 展示世界观、人物、主线、剧情阶段和章节卡生成进度。
- 初始化失败可从失败步骤继续。

### 2.3 设定中心

- 查看和编辑人物、关系、世界规则、地点和势力。
- 查看主线、阶段规划和章节卡。
- 修改正式设定时提示可能影响的章节和事实。

### 2.4 章节工作台

- 查看当前章节卡及相关上下文。
- 流式生成章节。
- 编辑、保存、重试和重新生成章节。
- 查看摘要、事件、人物变化、伏笔和连续性结果。
- 冲突未解决时不得推进正式进度。

### 2.5 导出

- 按章节查看完整作品。
- 第一阶段支持纯文本或 Markdown 导出。

## 3. 后续需求

- 章节版本历史和差异对比。
- 批注、局部重写与多轮润色。
- 自定义提示模板和文风模板。
- 封面、附件和作品公开页。
- 多模型选择、用量统计和订阅支付。
- 团队协作、角色权限和审核流程。

## 4. 非功能需求

- 桌面浏览器优先，同时适配平板和基础移动浏览。
- 长文本编辑不得因自动刷新丢失内容。
- 生成任务中断后可以重新连接或查询恢复。
- 关键操作记录审计信息。
- 前端不得保存模型 API Key。
- 页面需要明确的加载、空状态、失败、冲突和完成反馈。

## 5. 第一阶段验收

- 用户能完成注册登录和作品创建。
- 初始化流程可恢复，失败数据不污染正式状态。
- 用户能查看和修改主要小说设定。
- 用户能生成、编辑并保存第一章。
- 连续性冲突能被展示且阻止错误推进。
- 用户刷新页面后可继续当前任务。
- 用户能导出已确认章节。
