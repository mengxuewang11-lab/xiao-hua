# 用户 Web 开发文档

## 1. 目录约定

```text
web/
├── src/
│   ├── app/                 # Next.js 路由、布局和入口
│   ├── components/          # 纯通用组件
│   ├── design-system/       # Token 和基础业务组件
│   ├── features/            # 按领域组织
│   ├── lib/                 # API、认证和基础设施
│   ├── schemas/             # Zod 边界校验
│   └── stores/              # 少量客户端状态
├── public/
├── tests/
├── .nvmrc
└── package.json
```

## 2. 页面规划

```text
/
/login
/register
/workspace
/novels/new
/novels/[novelId]
/novels/[novelId]/settings
/novels/[novelId]/outline
/novels/[novelId]/chapters/[chapterId]
/account
```

核心 MVP 可以暂时跳过账户页面，用本地开发身份跑通小说闭环；进入多人线上版本前必须接入正式认证。

当前首页采用年轻化 ChatGPT 风格工作台布局：

- 左侧作品/会话栏固定在窗口中，作品列表内部滚动。
- 侧边栏支持像 ChatGPT 一样折叠为窄图标栏，也可以重新展开；状态保存到后端。
- 右侧工作区固定在窗口中，只允许聊天内容区域滚动，不使用窗口级滚动。
- 顶部展示当前会话标题、模型下拉、多主题切换和自定义颜色选择。
- 默认从后端读取最近会话；只有没有对话记录时才展示空白态欢迎区。
- 空白态主标题控制为 32px，避免压住实际工作内容。
- 左上角使用“花”字作为临时 Logo。
- 默认粉色主题，内置桃粉、莓红、葡萄、赛博蓝、薄荷、青柠、橘子、柠檬、海盐、夜樱、黑粉等主题，并支持自定义主题色。
- 使用纯 CSS 抽象光斑、动态细线和粒子光点营造氛围，不依赖外部图片素材。

当前 Web 对话工作台已经接入真实后端接口，但还没有打通 NovelAgent 自动写作状态机。它用于需求讨论、灵感输入、模型切换和聊天记录保存。

## 3. API 与 SSE

- Spring Boot OpenAPI 是接口契约来源。
- 当前本地 Web 通过 Next.js rewrite 将 `/api/*` 代理到 `http://localhost:8080/api/*`。
- 业务代码优先使用 `src/lib/api.ts` 中的 `apiUrl` 和接口常量，不在组件里散写后端地址。
- 当前工作台使用 `src/lib/api.ts` 的 `apiJson` 统一处理 JSON 请求和错误响应。
- `/api/chat/preferences` 保存主题、自定义色、侧边栏折叠状态和默认模型。
- `/api/chat/models` 返回后端开放的模型选项。
- `/api/chat/conversations` 与 `/api/chat/messages` 保存和恢复聊天记录。
- 生成 TypeScript 客户端，不手写重复 DTO。
- 生成任务先创建并返回 `taskId`，再订阅 SSE。
- SSE 事件包含 `status`、`content_delta`、`validation`、`completed`、`error`。
- 断线后查询任务状态并恢复，不默认重复提交。
- 写接口携带幂等键或版本号。

## 4. 编辑器

- Tiptap 保存结构化文档和可导出的纯文本内容。
- 自动保存使用防抖和版本号。
- 服务端返回 `409` 时进入冲突处理，不静默覆盖。
- AI 局部改写必须保留原文和建议版本。
- 第一阶段不实现多人协同编辑。

## 5. 质量要求

- TypeScript 严格模式。
- ESLint、Prettier 和类型检查进入提交检查。
- 页面组件不直接拼接后端地址或模型参数。
- shadcn/ui 组件修改集中维护。
- 长文本编辑器和非首屏模块按需加载。
- 核心操作满足键盘使用和基础无障碍要求。

## 6. 测试重点

- 登录和权限跳转。
- 初始化任务进度恢复。
- SSE 流式生成和断线恢复。
- 编辑自动保存与版本冲突。
- 连续性失败时不能确认章节。
- 从创建小说到保存第一章的 Playwright 主链路。

## 7. 本地命令约定

当前已初始化 Next.js 项目，统一使用 pnpm：

```text
pnpm install
pnpm dev
pnpm lint
pnpm typecheck
pnpm build
```

单元测试和 e2e 测试脚本在引入具体页面和交互后再补齐。

不提交 `node_modules`、`.next`、本地密钥和编辑器临时文件。

## 9. 部署

第一阶段：

```text
Next.js → Spring Boot → MySQL
```

上线后可由 Nginx 或平台网关统一 HTTPS、域名和反向代理。Redis 与 Docker 不作为开始开发的前置条件。
