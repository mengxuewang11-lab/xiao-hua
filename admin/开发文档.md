# 管理系统开发文档

## 1. 目录约定

```text
admin/
├── src/
│   ├── app/                 # 启动、路由和全局插件
│   ├── layouts/
│   ├── components/
│   ├── features/
│   ├── services/            # API 客户端和拦截器
│   ├── stores/
│   ├── permissions/
│   ├── styles/
│   └── utils/
├── public/
├── tests/
├── .nvmrc
└── package.json
```

## 2. 页面规划

```text
/login
/dashboard
/users
/users/:userId
/novels
/novels/:novelId
/generation-tasks
/model-configs
/audit-logs
/roles
/system
```

管理系统在后端主链路稳定后初始化，不应先于数据库和用户端闭环开发。

## 3. 状态边界

- TanStack Query 管理列表、详情和服务端缓存。
- Pinia 保存管理员会话、菜单和纯客户端状态。
- Axios 只负责 HTTP 传输、鉴权头和统一错误适配。
- URL 保存分页、筛选和查询条件。
- 表单优先使用 Element Plus Form。

## 4. 权限

- 管理 API 统一使用 `/admin-api`。
- 后端 Spring Security 是最终权限边界。
- 权限码使用资源与动作，例如 `user:read`、`user:disable`。
- 前端路由、菜单、按钮和字段按权限展示。
- 管理员权限变化后，旧会话应及时失效。
- 高风险操作需要二次确认和审计。

## 5. 数据与操作

- 列表统一服务端分页、排序和筛选。
- 删除优先采用可恢复状态，不直接物理删除。
- 批量任务限制数量并展示部分失败。
- 导出需要权限、规模限制和审计。
- 敏感正文和模型配置的访问需要额外记录。
- API Key 永不通过管理接口返回明文。

## 6. 测试重点

- 未登录、无权限和越权访问。
- 菜单权限与后端权限一致。
- 用户禁用、作品冻结和任务重试。
- 模型密钥脱敏。
- 高风险操作确认与审计记录。
- 分页、筛选、批量操作和部分失败。

## 7. 本地命令约定

```text
pnpm install
pnpm dev
pnpm lint
pnpm typecheck
pnpm test
pnpm test:e2e
pnpm build
```

## 8. 部署与安全

- 使用独立域名或内部域名。
- 正式环境只允许 HTTPS。
- 启用严格会话策略和必要的多因素认证。
- 管理端与用户 Web 分别构建发布。
- Nginx 或网关设置安全响应头和访问限制。
