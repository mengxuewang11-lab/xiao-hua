# 管理系统开发需求文档

## 1. 产品目标

为运营、审核和技术支持人员提供安全、可审计的内部管理工具，支持用户、作品、生成任务、模型配置和系统运行状态管理。

## 2. 第一阶段需求

### 2.1 管理员与权限

- 管理员登录、退出和会话超时。
- 角色、菜单和操作权限控制。
- 登录失败与高风险操作审计。

### 2.2 用户管理

- 按 ID、昵称、邮箱和状态查询用户。
- 查看用户基础信息、作品数量和用量。
- 禁用或恢复账户。
- 敏感信息默认脱敏。

### 2.3 作品管理

- 查询作品、题材、状态和最近更新时间。
- 查看初始化与章节生成状态。
- 对违规作品执行隐藏、冻结或恢复。
- 不默认提供直接修改用户正文的能力。

### 2.4 生成任务

- 查询初始化和章节生成任务。
- 查看任务状态、耗时、模型、Token 用量和归一化错误。
- 对符合条件的失败任务发起重试。
- 终止长期无响应的任务。

### 2.5 模型与系统配置

- 管理可用模型、用途、限流和启停状态。
- API Key 仅允许服务端安全存储，页面只显示是否已配置。
- 查看基础运行指标和最近错误。

## 3. 后续需求

- 内容审核队列和申诉处理。
- 套餐、订单、退款和配额管理。
- 提示模板版本管理及灰度发布。
- 模型成本、质量和失败率分析。
- 公告、消息和运营活动。
- 数据导出审批。

## 4. 非功能需求

- 所有接口必须经过服务端权限校验。
- 管理操作记录操作者、时间、对象、动作和结果。
- 高风险操作要求二次确认，必要时要求再次验证身份。
- 日志和页面不得显示完整密钥、密码或用户敏感正文。
- 列表接口必须分页并限制导出规模。
- 管理系统应限制访问来源并启用更严格的会话策略。

## 5. 第一阶段验收

- 不同角色只能访问授权菜单和接口。
- 管理员可以查询用户、作品和生成任务。
- 账户禁用、任务重试等操作有完整审计记录。
- 模型密钥不会通过管理接口返回。
- 普通用户凭证无法访问任何管理 API。
- 关键筛选、分页和错误提示可正常使用。
