# 管理系统技术栈选型文档

## 1. 定位

本目录后期存放内部运营、审核和技术支持系统。管理系统与用户网站独立构建、独立部署、独立授权。

## 2. 正式选型

```text
框架：Vue 3
语言：TypeScript
构建工具：Vite
UI：Element Plus
样式：SCSS + CSS Variables
路由：Vue Router
客户端状态：Pinia
服务端状态：TanStack Query for Vue
HTTP：Axios
工具：VueUse
图表：ECharts
测试：Vitest + Vue Test Utils + Playwright
包管理器：pnpm
```

## 3. 选择理由

- Vue 3 与 Element Plus 是成熟的中后台组合。
- 表格、表单、分页、弹窗和筛选组件完整。
- Vite 开发与构建速度快。
- TypeScript 能与 OpenAPI 生成客户端结合。
- 国内资料和长期维护生态成熟。

## 4. 服务端关系

```text
Vue Admin
→ /admin-api
→ Spring Security + RBAC
→ 领域服务 + 审计日志
→ MySQL
```

前端路由与按钮权限只改善体验。后端必须对每个管理接口执行权限校验。

管理端请求约定：

```text
真实后端地址：http://localhost:8080/admin-api/{控制器}/{接口名}
前端 baseURL：http://localhost:8080/admin-api
业务代码路径：/{控制器}/{接口名}
```

## 5. UI 规范

- Element Plus 提供基础控件。
- SCSS 与 CSS Variables 负责品牌主题。
- 不与 Tailwind 或第二套完整 UI 库混用。
- 普通表格使用 Element Plus Table。
- 只有真实出现大数据透视、树形聚合需求时才评估 AG Grid。
