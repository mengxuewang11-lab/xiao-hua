# 小花无限小说工坊

面向网文创作者的自主 AI 小说创作智能体。用户可以输入一个想法，也可以让系统根据市场数据提出创意。用户选定方向后，系统主动完成世界观、人物、全书规划、伏笔和章节卡，并按计划持续写作、检查、修正和更新小说圣经，只在重要决策处询问用户。

## 产品北极星

```text
用户负责目标、偏好和关键选择
→ 小说总导演负责研究、规划、写作、检查、修正和持续推进
→ 普通问题自动处理
→ 重大且不可逆的变化才暂停并请求用户决策
```

本项目不是把“脑洞、人物、世界观、大纲、章节”做成一组需要用户逐个点击的 AI 按钮，也不是复杂的资料管理工作台。人物、世界、时间线、伏笔和 StoryBible 主要由系统在后台维护，用户可以查看和修改，但不需要手工驱动每个步骤。

## 项目形态

```text
Flutter App ───────────┐
Next.js 用户网站 ──────┼→ Spring Boot 共享后端 → MySQL
Vue 3 管理系统 ────────┘                   → AI Model Provider
```

三个客户端共用一个 Java 后端。当前采用模块化单体，不拆微服务。
