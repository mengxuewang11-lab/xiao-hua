# App 开发需求文档

## 1. 产品目标

为小说创作者提供适合移动场景的创作入口。第一阶段强调查看、触发生成和简单修改，不追求替代桌面端的完整编辑能力。

## 2. 目标用户

- 随时记录小说灵感的创作者。
- 在移动设备上查看生成进度和章节的用户。
- 需要快速续写、审阅和调整内容的用户。

## 3. 第一阶段需求

### 3.1 账户

- 登录、退出和登录状态保持。
- 查看基础账户信息。
- Token 失效后安全地重新登录。

### 3.2 作品

- 查看作品列表、状态和最近更新时间。
- 查看小说概览、世界观、人物和剧情阶段。
- 创建小说，填写创意、题材和基础生成配置。

### 3.3 章节

- 查看章节列表、章节卡、正文和摘要。
- 发起当前章节生成。
- 实时显示生成状态和正文增量。
- 生成失败后查看原因并重试。
- 保存轻量文本修改。

### 3.4 基础体验

- 支持加载、空数据、失败和离线状态。
- 对未保存修改提供离开提醒。
- 长文本阅读支持字号、行距和主题调整。

## 4. 后续需求

- 创意随手记和本地草稿。
- 评论、批注和版本对比。
- 生成完成推送通知。
- 离线阅读与联网同步。
- 分享导出和多设备同步。
- 订阅、套餐与用量查询。

## 5. 非功能需求

- Android 与 iOS 主流程行为一致。
- API Key 和敏感配置不得打包进客户端。
- 弱网下不得重复提交生成任务。
- 关键写操作需要幂等标识。
- 正文缓存必须按用户和作品隔离。
- 首屏、崩溃率和接口失败率应可监控。

## 6. 第一阶段验收

- 用户可以登录并查看自己的作品。
- 用户可以创建小说并看到初始化进度。
- 用户可以查看设定和已有章节。
- 用户可以生成一章并实时查看内容。
- 失败任务可以安全重试，不产生重复章节。
- 应用重启后可以恢复登录和最近浏览位置。
