# 共享后端技术栈选型文档

## 1. 定位

`backend` 后期存放 App、用户 Web 和管理系统共同使用的后端。第一阶段采用模块化单体。

## 2. 正式选型

```text
语言：Java 17
框架：Spring Boot
构建：Maven
Web：Spring MVC
校验：Jakarta Validation
安全：Spring Security
数据访问：Spring JDBC / JdbcTemplate
数据库：MySQL 8.0
迁移：Flyway
接口文档：springdoc-openapi
外部 HTTP：RestClient
测试：JUnit 5 + Spring Boot Test + Testcontainers
```

## 3. 选择原则

- 三个客户端共用业务规则和数据。
- Spring Boot 适合认证、权限、事务、审计和长期工程化。
- Java 17 为当前项目运行基线。
- MySQL 已完成本地安装。
- Flyway 是数据库结构与基准数据演进的唯一入口。
- 模块化单体降低早期部署和调试成本。

## 4. Flyway 强制规范

```text
迁移目录：src/main/resources/db/migration/
版本迁移：V{version}__{description}.sql
可重复迁移：R__{description}.sql
Hibernate：ddl-auto=validate
```

- 已执行的 `V` 迁移禁止修改、删除或重命名。
- 数据库变化通过新增更高版本迁移前滚。
- 开发、测试、预发布和生产使用同一套迁移。
- `R` 迁移只用于视图等适合重复创建的对象。
- 生产环境禁止 Flyway `clean`。
- `repair` 只能在确认历史表与文件状态后人工执行。

## 5. 暂缓引入

- Spring Cloud 与微服务。
- Redis。
- Kafka/RabbitMQ。
- Elasticsearch。
- 向量数据库。
- Kubernetes。

这些能力只在真实负载或业务需求出现后加入。
