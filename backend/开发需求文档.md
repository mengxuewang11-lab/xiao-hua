# 共享后端开发需求文档

## 1. 核心目标

为 App、用户 Web 和管理系统提供统一、安全、可恢复的业务 API，跑通小说初始化、逐章生成、一致性检查和正式事实更新。

## 2. 首轮能力

- MySQL 数据模型和 Flyway 迁移。
- 小说项目创建、加载和进度管理。
- 世界观、人物、主线、阶段和章节卡存取。
- 章节正文与结构化元数据保存。
- StoryBible 正式事实和冲突记录。
- 生成任务状态、幂等和失败恢复。
- Fake Model Provider。
- Web 对话工作台接口。
- 主题、自定义色、侧边栏折叠状态和默认模型持久化。
- 聊天会话、用户消息、助手消息和模型调用记录持久化。
- 智谱/Kimi 对话模型接入。
- REST、SSE 和 OpenAPI。
- 统一异常、日志和请求追踪。

## 3. 后续能力

- 用户账户与 JWT 认证。
- 管理员 RBAC 和审计。
- NovelAgent 自动写作主链路的真实模型 Provider。
- 模型用量、限流和成本统计。
- Redis、后台任务和对象存储。
- 支付、订阅和配额。

## 4. 非功能需求

- AI 输出未经校验不得成为正式数据。
- 章节确认和状态变化必须原子提交。
- 写接口支持幂等。
- 当前本地开发允许明文保存模型 Key。
- 数据库应用账户不得使用 `root`。
- 用户 API 与管理 API 权限隔离。
- 所有迁移可重复部署且不可手工漂移。
- 已在共享环境执行的迁移文件不得修改或删除。
- 数据库结构修正必须通过新增 Flyway 版本前滚。
- Hibernate 只能校验表结构，不得自动创建或修改表。

## 5. Web 对话工作台验收

- 能读取可用模型列表。
- 能保存和读取主题、自定义色、侧边栏折叠状态和默认模型。
- 能创建聊天会话。
- 能保存用户消息。
- 能调用智谱/Kimi 模型接口。
- 模型失败时能保存用户消息和失败记录。
- 刷新页面后能恢复偏好、会话和消息。
- Swagger 中 `/api/chat/**` 接口有中文说明和 Bearer 认证标记。

## 6. 首轮验收

- 能执行 Flyway 创建完整基础表。
- 空数据库与已有数据库都能安全执行待运行迁移。
- Flyway 校验能发现已执行脚本被篡改。
- 能创建并重新加载小说项目。
- Fake Provider 能跑通初始化。
- 能保存第一章及全部状态变化。
- 冲突章节不会推进进度。
- 重试不会产生重复数据。
- OpenAPI 可访问且主要接口有测试。
